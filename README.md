# Aaditya Mohan — Portfolio Website (v2.0)

A high-performance, modern developer portfolio SPA designed for **Aaditya Mohan** (Software Engineer & Backend Specialist).

Built with **React 19 + TypeScript + Vite + Tailwind CSS + Framer Motion + Lucide Icons**.

## 🚀 Features
- **Modern Blueprint & Terminal Aesthetic**: Cloud architect & API-first theme with real-time status badges (`200 OK`, `GET /about`, `POST /contact`).
- **Interactive Terminal HUD**: Full keyboard support with commands like `help`, `skills`, `projects`, `exp`, `curl /api/profile`, `contact`, `theme`, `sudo hire-aaditya`, command history, and confetti celebrations.
- **Command Palette (`⌘K` / `Ctrl+K`)**: Keyboard-driven quick navigation, section jumping, and actions.
- **Dark & Light Mode**: Smooth theme switching with system preference detection and `localStorage` persistence.
- **Interactive Project Showcase**: Filter by domain (*All*, *Full Stack*, *Backend & Microservices*, *GenAI & Cloud*) with architecture highlights.
- **Interactive Contact Deck**: 1-click clipboard copy for email and phone with custom toast feedback, plus a simulated `POST /contact` dispatch console.
- **Mobile Responsive**: Custom glassmorphism navigation drawer and fluid layouts for desktop, tablet, and mobile screens.

## 🛠️ Tech Stack
- **Framework**: React 19, Vite, TypeScript
- **Styling**: Tailwind CSS, PostCSS, Autoprefixer
- **Animations & Effects**: Framer Motion, Canvas Confetti
- **Icons**: Lucide React + custom SVG icons
- **Fonts**: JetBrains Mono, Space Grotesk, Plus Jakarta Sans

## 💻 Getting Started

### Install Dependencies
```bash
npm install
```

### Run Local Dev Server
```bash
npm run dev
```

### Production Build
```bash
npm run build
```

### Preview Production Build
```bash
npm run preview
```

## 📦 Deployment
The production bundle is generated in the `dist/` directory and can be deployed to **Vercel**, **Netlify**, or **GitHub Pages**.
